> Optimization of Hardfacing Coating Deposition by Computational Analysis of AC-HVAF Spray-Plume Diagnostics. 

## Overview

The repository provides a **minimal qualitative analysis example notebook operating on a single representative set of experimental conditions** of an Activated-Combustion High-Velocity Air-Fuel (**AC-HVAF**) plume characterization. The scope of the qualitative analysis consists consists in calculating plume length  for each video frame  as the distance from a selected anchor to the first rightward crossing of a drop-off threshold defined as a fixed fraction of that frame’s local peak intensity (see figures/Figure_4b.jpg).

The **full 15-setting dataset** is archived on Zenodo (DOI: 10.5281/zenodo.17468557) under CC BY-NC 4.0.

## Data in this repository

This repository contains **one representative condition** – primary fuel pressure **118 psi**, air pressure **108 psi** and secondary fuel **80 psi** – as a single CSV derived from the corresponding video (stack of per-frame, 1D axial image intensity profiles along the jet-axis). The full multi-condition dataset is released on Zenodo: 10.5281/zenodo.17468557

- **Rows**: spatial coordinate along the jet axis (x, in mm), monotonically increasing.
- **Columns**:  
  - `x_mm` — physical coordinate (mm).  
  - `luma 25`, `luma 26`, …, `luma 982` — one column **per video frame** (Relative intensity, a.u.).
  The numeric suffix is the **1‑indexed** frame counter at **240 fps** (timestamp = (index−1)/240 s).

- **File naming**: `<primary fuel>_<air>_<secondary fuel>.csv`
 On this repository: `118_112_80.csv`

## Files in this repository

- `118_112_80.csv` - per-frame axial intensity profiles  
- `AC_HVAF_flame_length_analysis.ipynb` — reproduces figures/GIFs for the example  
- `requirements.txt`- pinned Python packages.
- **`env.txt`** — *Runtime snapshot (not an install spec).*  
  Auto-generated by the notebook on each run. Captures the exact versions of Python and key libraries that produced the outputs (e.g., `numpy`, `pandas`, `scipy`, `matplotlib`, platform). 
- **`params.json`** — *Analysis parameters used in this run.*  
  Auto-generated by the notebook. Records all tunable parameters used for detection/measurement (e.g., `THRESHOLD_FRAC`, `PEAK_DISTANCE`, `PEAK_PROM_REL`, `MIN_HEIGHT_REL`, `SMOOTH_WIN`, `SMOOTH_POLY`, `RADIUS`).
